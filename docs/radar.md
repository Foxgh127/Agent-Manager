# Codex 雷达

## 数据与评分

综合智能读取 Codex Radar 的软件工程、视觉空间两个公开接口，按有效题量加权，动态纳入 Astra 等模型。它是社区基准，不是 OpenAI 的官方模型评级。[数据源](https://codexradar.com/)

额度雷达读取原站网页中的美元实测卡片。核对时，页面为 20x Pro：Luna **$1,145.10**、Sol **$1,919.83**，标注“8月25日12:36更新”。旧 `current.json` 仍是另一组旧数据，所以不能只读取该文件。页面未给出的测量周期、年份或时区不会补造。

## 小时预警

开启监测后，启动立即检查，运行期间每 60 分钟检查一次，全天有效。手动检查和后台检查合并并发；失败遵循来源退避和 Retry-After。关闭应用停止检查，已关闭监测开关的用户不会被重新开启。

综合证据分考虑来源身份、发布时间、内容是否明确、影响范围，以及去除转录重复后的证据。分为“信息、关注、预警、确认”；社区预测分独立展示，不视为发生概率。个人账号重置、一般服务故障恢复和全球额度重置分别处理。

新事件或等级提升才产生通知。同一信号跨重启去重；提交失败保留有界队列，每 5 分钟重试，最多 3 次，且不延长原信号有效期。无常驻托盘时也能向 Windows 提交通知；系统通知设置仍可能影响横幅显示。

公开聚合站可能转录错误，带官方链接也不等于本软件已独立核验原帖。提醒会保留原始来源，实际到账仍以账号为准。

## 重置历史

历史只显示来源公布的发生时间和发布时间，不显示本机发现时间。只有日期或月份时按对应精度展示，不补小时分钟。

当前原站九月月表记为 **3 次重置卡**，同页文字说明仍为 **2 次**；另提到 9 月 8 日一次直接重置。软件保留三次卡的月度统计并标注两种口径的差异，没有伪造三条独立日期。未来“将补发”的帖子保留为预警线索，不当作已经完成。
