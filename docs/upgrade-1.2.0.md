# Agent Manager 1.2.0 升级与验收记录

目标：参考 Cockpit、CC Switch、Sub2API、CLIProxyAPI 的近期更新，补全适用于本项目的功能，重点优化整个调度中心、请求调度和不同安装位置/权限下的兼容性，验证后发布 1.2.0。

## 已核对的参考版本（2026-09-19）

通过 GitHub Releases API 读取各项目最近六次发布；原始响应保存在本地 `artifacts/upstream-1.2.0/`，不作为应用依赖或运行时指令。

| 项目 | 阅读范围 | 适用方向 |
| --- | --- | --- |
| [Cockpit](https://github.com/jlcodes99/cockpit-tools/releases/tag/v1.3.57) | 1.3.52–1.3.57 | 商店更新路径重检测、来源并发控制、当前模型压缩、真实模型目录、配置不串写、工具历史配对 |
| [CC Switch](https://github.com/farion1231/cc-switch/releases/tag/v3.20.3) | 3.19.1–3.20.3 | 原生 Responses 优先、配置修改保留独立字段、Windows 增量用量、恢复事务、CLI 发现、来源能力约束 |
