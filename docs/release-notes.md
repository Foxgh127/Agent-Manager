# Agent Manager 1.0.1

个人练手项目，开发工作由 Codex 完成，仅供个人学习和测试，非官方产品。

- 修复重开应用时采样重置：保留有效区间，采集中断后建立新起点，同账号重复激活不再清零。
- 用量按模型区分输入、缓存输入和输出，显示 API 美元等值；证据足够时估算当前额度的总量和剩余。
- 未知型号和不完整记录明确标注，旧未知记录不阻断之后完整区间；历史和文件容量有界，支持长期继续采样。
- 修复原生子代理策略的配置误报、旧诊断警告残留，以及激活完成后首页没有刷新的竞争问题。
- 启动优先读取持久缓存，减少强制网络发现和全量历史扫描；本地 CLI 探测按安装身份缓存并合并并发请求。
- 补充策略正文与 Codex 完整说明的关系，整理生成目录与可预览的清理工具。
- 新增 Sub2API、CLIProxyAPI 与 LiteLLM 对比文档；没有更换本地反代引擎。

美元值按 2026-09-10 核实的标准短上下文参考价折算，不是订阅余额或账单，不包含无法确认的附加费用。旧版已清空的配对记录无法凭空恢复。

1.0.0 可使用内置更新入口升级。首次安装或缓存失效仍需探测本地 Codex；没有关闭现有 Codex 来进行本轮验证。

## 1.0.0

个人练手项目，开发工作由 Codex 完成，仅供个人学习和测试，非官方产品。

- 采用 src 包布局，拆分原核心和应用大文件，按领域整理测试、构建与文档。
- 保留现有功能，清理历史产物、重复说明及旧构建脚本。
- 修复维护区状态文字错位；0周期限制不再显示为“只能使用0美元”。
- FastAI 等站点拒绝后台访问时支持通过网页刷新；验证后复用同账号隐藏窗口，不绕过网站验证。
- 配置窗口支持手动备份、删除、分页和保护原因；自动备份与恢复前原件共用最近三份不同内容上限。
- 改进API完整历史的加密推理兼容重试，保留原始对话，避免跨身份失败重放。
- 资源和数据位置与工作目录分离，保留不同Codex安装方式检测，缺少原生窗口环境时退回浏览器。
- 产品版本统一为1.0.0，后续版本信息从同一个源生成；新系列不会误更新到旧9.x。

9.x用户请手动下载一次1.0.0，结束旧管理器后运行新版。后续仍可一键更新。
