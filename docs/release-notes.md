# Agent Manager 1.2.2

- 修复 Windows 更新后应用关闭但不自动重新打开的问题：更新助手使用专用重启参数，绕过残留运行状态文件，并以正常桌面窗口启动新版本。
- 保留更新安装的 SHA-256、进程身份、健康接口、窗口就绪和失败回滚校验；增加更新重启参数与普通窗口启动的回归覆盖。

# Agent Manager 1.2.1

- 修复中转站与 Cockpit 风格 API 导入的模型识别：兼容多层目录、模型对象、别名字段、能力元数据和常见 API Key 认证头，保留可用的手动模型目录。
- 扩展余额与用量识别，支持余额、剩余额度、总额度、已用量、无限额度、货币、到期时间和多种中转站接口路径；余额不可用时仍可完成模型导入。
- 修复电脑只有 Codex Desktop 内置运行时而没有独立 CLI 时更新按钮不下载的问题；现在“下载最新版”会自动选择 npm 或官方校验平台包，并独立复检 CLI。
- 修复中转站 Key 模型对象被误判为零个模型，以及删除账号触发全量刷新；删除操作改为局部乐观更新，减少等待和无关刷新。

# Agent Manager 1.2.0

- 将调度中心的“保存”和“恢复默认”统一为带快照、预检、回滚和启动回验的事务；配置文件、模型目录、Agent 文件、密钥和环境变量任一步失败都会恢复原状态。
- 新增调度草稿预检，保存前显示有效模型数、受管 Agent 数、本地网关需求和原生模式提示；原生模式明确交由 Codex 自己决定，单代理模式才会关闭多代理工具。
- 号池增加单来源并发上限和有界排队等待，可按账号或 Provider 隔离负载；取消、超时和切换失败都会释放来源租约，保持会话身份绑定。
- 用量统计继续被动记录响应正文模型、系统指纹和路由证据；只有响应模型与配置不一致时显示告警，缺失证据保持未知，不把指纹变化单独判定为“降智”。
- 复查官方 OAuth 与第三方中转路径的边界：官方请求只使用原生 Codex Responses 路径和受限身份头，不生成指纹、不重放首个输出、不跨身份续接；Sub2API 等仅用于用户主动导入的站点适配。
- 统一商店版、便携版、中文/空格/UNC 路径和普通权限下的数据目录诊断，保留现有设置与账号，不写入受保护安装目录或全局凭据环境变量。
- 参考 Cockpit 1.3.57、CC Switch 3.20.3、Sub2API 0.2.5 与 CLIProxyAPI 7.3.7 的近期修复方向，未引入其代理引擎、登录流程或外部运行时依赖。

# Agent Manager 1.1.9

- 修复微软商店版 Codex 切换官方账号时直接启动 `WindowsApps` 路径导致的 `WinError 5`；默认使用 AppUserModelId，隔离账号和 Provider 使用包身份启动，并避免重复启动桌面进程。
- 新增“单代理模式”，同步 Codex 官方多代理开关并在切换模式时恢复原配置；明确“Codex 原生模式”只释放管理器接管权，已打开的任务需重启或新建任务才会读取新配置。
- 加强 App Server 探针、CLI 回退和旧路径识别，禁止受保护商店路径直接执行；官方账号令牌、`CODEX_HOME` 和 CLI 覆盖项不再写入用户全局环境变量。
- 改善切换失败的历史状态提示，保留后续更新并补充商店启动、账号隔离和单代理策略回归测试。

# Agent Manager 1.1.8

- 修复临时 Agent 配置没有历史基线时的退出恢复逻辑；内容仍匹配管理器指纹时自动接管并清理孤立恢复记录，避免软件卡在“关闭未完成”。
- 更新失败信息绑定安装版本和发布检查结果；旧版本失败记录不会遮蔽新版本，安装未安全退出时会保留原版本并显示具体原因。
- 增加关闭恢复和旧安装失败回归测试，覆盖残留进程、恢复记录和重试路径。

# Agent Manager 1.1.7

- 技能中心按技能根目录合并模块，支持展开、搜索、分页和本地状态筛选；保留每个模块独立的启停、删除和安装行为。
- 技能清单支持折叠式 YAML 描述，修复多行元数据读取，并完成 61 个本机技能的 frontmatter 校验与触发边界整理。
- 调度提示词和本机 `AGENTS.md` 收敛为渐进披露、收益门控委派和可验证返回契约，减少重复规则与误触发。
- 新增安全交互配置 profile，完善 PaperSpine 及高副作用技能的显式调用策略。

# Agent Manager 1.1.6

- 切换账号和中转站改为短请求后台任务，进度可重连轮询；关闭管理器会等待后台切换完成，避免 120 秒请求超时和半写入配置。
- 首屏改为缓存优先加载，不再把 Codex CLI 模型探测阻塞在 `/api/state`；断网、CLI 暂不可用或本地服务短暂重启时会显示可重试的错误界面。
- 延迟启动后的额度刷新，保留最近一次有效卡片数据，并把多次 Windows 环境变量广播合并为一次，减少卡片重复刷新和切换等待。
- 配置一致性诊断增加漂移指纹并与修复写入使用同一组锁，降低后台刷新、切换和紧急修复之间的竞态。
- 校验近期 Cockpit 兼容行为：工具调用继续按 `call_id` 配对，Windows Store/桌面 Codex 启动保持受保护路径检查和统一超时回退。
