# Agent Manager 1.1.9

- 修复微软商店版 Codex 切换官方账号时直接启动 `WindowsApps` 路径导致的 `WinError 5`；默认使用 AppUserModelId，隔离账号和 Provider 使用包身份启动，并避免重复启动桌面进程。
- 新增“单代理模式”，同步 Codex 官方多代理开关并在切换模式时恢复原配置；明确“Codex 原生模式”只释放管理器接管权，已打开的任务需重启或新建任务才会读取新配置。
- 加强 App Server 探针、CLI 回退和旧路径识别，禁止受保护商店路径直接执行；官方账号令牌、`CODEX_HOME` 和 CLI 覆盖项不再写入用户全局环境变量。
- 改善切换失败的历史状态提示，保留后续更新并补充商店启动、账号隔离和单代理策略回归测试。

# Agent Manager 1.1.8

- 修复临时 Agent 配置没有历史基线时的退出恢复逻辑；内容仍匹配管理器指纹时自动接管并清理孤立恢复记录，避免软件卡在“关闭未完成”。
- 更新失败信息绑定安装版本和发布检查结果；旧版本失败记录不会遮蔽新版本，安装未安全退出时会保留原版本并显示具体原因。
- 增加关闭恢复和旧安装失败回归测试，覆盖残留进程、恢复记录和重试路径。

# Agent Manager 1.1.7

- 技能中心按技能根目录合并模块，支持展开、搜索、分页和本地状态筛选；保留每个模块独立的启停、删除和安装行为。
- 技能清单支持折叠式 YAML 描述，修复多行元数据读取，并完成 61 个本机技能的 frontmatter 校验与触发边界整理。
- 调度提示词和本机 `AGENTS.md` 收敛为渐进披露、收益门控委派和可验证返回契约，减少重复规则与误触发。
- 新增安全交互配置 profile，完善 PaperSpine 及高副作用技能的显式调用策略。

# Agent Manager 1.1.6

- 切换账号和中转站改为短请求后台任务，进度可重连轮询；关闭管理器会等待后台切换完成，避免 120 秒请求超时和半写入配置。
- 首屏改为缓存优先加载，不再把 Codex CLI 模型探测阻塞在 `/api/state`；断网、CLI 暂不可用或本地服务短暂重启时会显示可重试的错误界面。
- 延迟启动后的额度刷新，保留最近一次有效卡片数据，并把多次 Windows 环境变量广播合并为一次，减少卡片重复刷新和切换等待。
- 配置一致性诊断增加漂移指纹并与修复写入使用同一组锁，降低后台刷新、切换和紧急修复之间的竞态。
- 校验近期 Cockpit 兼容行为：工具调用继续按 `call_id` 配对，Windows Store/桌面 Codex 启动保持受保护路径检查和统一超时回退。
