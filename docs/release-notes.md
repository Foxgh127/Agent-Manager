# Agent Manager 1.1.0

个人练手项目，代码、界面、文档和开发工作由 Codex 完成，仅供个人学习与测试，非官方产品。

- 升级独立 Python 反代：参考 CPA 的成熟方法，加入持久会话身份绑定、每模型轮询与在途负载选择；不内嵌 CPA/Sub2API 服务。
- 同名 API Provider 共享模型支持受控候选选择与首输出前安全回退；专属路由、会话和可信续轮保持原身份。
- 完整遵循远端 Retry-After；文本、推理、工具输出或已报告 Token 消耗后不再盲目重放，异常路径释放上游连接。
- 加强 API 地址与 Key 文本、嵌套/批量账号导入，支持明确来源的短期 OAuth access token；错误单项隔离，不导入管理密钥或伪造刷新链。
- 计量记录按实际型号、单请求上下文档位、服务层级及缓存读写分组；旧统计迁移不重复计数。
- 卡片收敛为一行“预计总额度”，支持有证据的点估值或条件区间；详细依据和可比周期的容量变化线索点击展开。
- 区分模型总上下文、最大输入与 Codex 预留比例，修复配置和目录上限不同步以及误导性的窗口换算。
- 普通推送只运行检查；以后发行版仍需明确授权后发布。本次发布已获得用户授权。

WebSocket 仍为串行桥接；不承诺任意厂商协议自动互转。估算不是账单或固定官方额度，观察到容量变化也不能单独证明官方削减。完整说明见仓库使用文档。
