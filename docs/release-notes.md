# Agent Manager 1.0.0

个人练手项目，开发工作由 Codex 完成，仅供个人学习和测试，非官方产品。

- 采用 src 包布局，拆分原核心和应用大文件，按领域整理测试、构建与文档。
- 保留现有功能，清理历史产物、重复说明及旧构建脚本。
- 修复维护区状态文字错位；0周期限制不再显示为“只能使用0美元”。
- FastAI 等站点拒绝后台访问时支持通过网页刷新；验证后复用同账号隐藏窗口，不绕过网站验证。
- 配置窗口支持手动备份、删除、分页和保护原因；自动备份与恢复前原件共用最近三份不同内容上限。
- 改进API完整历史的加密推理兼容重试，保留原始对话，避免跨身份失败重放。
- 资源和数据位置与工作目录分离，保留不同Codex安装方式检测，缺少原生窗口环境时退回浏览器。
- 产品版本统一为1.0.0，后续版本信息从同一个源生成；新系列不会误更新到旧9.x。

9.x用户请手动下载一次1.0.0，结束旧管理器后运行新版。后续仍可一键更新。
