# Agent Manager 9.13.0

仅供个人练手、学习与测试；本项目代码、界面、提示词和文档工作全部由 Codex 完成，非 OpenAI/Anthropic 官方项目。

- Codex API 登录名跟随卡片，模型名去掉站点/分组附加文字。
- Agent Manager、Desktop、CLI 合并到三列版本维护区；自身更新内置 GitHub 发布源并支持校验后安装重启。
- 支持通过 Microsoft Store CLI 在管理器内检查/更新 Codex Desktop。
- 普通关闭先结束 Codex、确认配置恢复，再退出；失败保留恢复入口。
- 账号余额与 Key 额度分离，零余额可刷新，过期结果明确标记。
- Astra 优先的子代理任务契约及 GPT-5.6 模型工作要求，来源见源码文档。

下载 EXE 至固定、可写文件夹运行。检查更新失败不影响当前安装。实际 API/模型可用性由账号和上游服务决定。
