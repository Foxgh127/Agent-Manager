# Agent Manager 1.1.6

- 切换账号和中转站改为短请求后台任务，进度可重连轮询；关闭管理器会等待后台切换完成，避免 120 秒请求超时和半写入配置。
- 首屏改为缓存优先加载，不再把 Codex CLI 模型探测阻塞在 `/api/state`；断网、CLI 暂不可用或本地服务短暂重启时会显示可重试的错误界面。
- 延迟启动后的额度刷新，保留最近一次有效卡片数据，并把多次 Windows 环境变量广播合并为一次，减少卡片重复刷新和切换等待。
- 配置一致性诊断增加漂移指纹并与修复写入使用同一组锁，降低后台刷新、切换和紧急修复之间的竞态。
- 校验近期 Cockpit 兼容行为：工具调用继续按 `call_id` 配对，Windows Store/桌面 Codex 启动保持受保护路径检查和统一超时回退。
